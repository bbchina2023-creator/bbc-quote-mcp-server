## Primary manager workflow — frozen

For every new deal:

1. The manager provides the input documents for that deal in the current ChatGPT conversation.
2. ChatGPT reads and reconciles only those current-deal documents as the source of deal-specific values.
3. If a downstream deterministic operation requires Drive IDs/URLs, ChatGPT handles that bridge internally.
4. Previous deals may supply only approved model rules, mappings and regression expectations. Their deal-specific values are not sources for a new deal.
5. The manager is asked only for information actually absent from all current-deal sources or genuinely contradictory after source-priority reconciliation.
6. Deterministic calculation/document logic performs the financial calculations and produces the verified Google Sheets/XLSX/PDF package.
7. QA reconciles source lineage, calculation totals, payment totals, unit economics and client rendering before release.
