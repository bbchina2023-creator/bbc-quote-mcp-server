## Primary manager workflow — frozen

For every new deal:

1. The manager provides the input documents for that deal in the current ChatGPT conversation.
2. ChatGPT reads and reconciles only those current-deal documents as the source of deal-specific values.
3. If a downstream deterministic operation requires Drive IDs/URLs, ChatGPT itself stores/resolves the files in Google Drive and passes the required references. This is an internal technical bridge, not a manager step.
4. Previous deals may supply only approved model rules, mappings and regression expectations. Their client, route, payment schedule, amounts, items or other deal-specific values must never be copied into a new deal.
5. ChatGPT asks the manager only for information that is actually absent from all current-deal sources or is genuinely contradictory after source-priority reconciliation.
6. The deterministic calculation/document layer performs the financial calculations and produces the verified Google Sheets/XLSX/PDF package.
7. QA must reconcile source lineage, calculation totals, payment totals, unit economics and client-document rendering before release.

This direct-chat path is the primary production UX. Drive-first is permitted only as an internal technical bridge. The manager is not required to manually move files between ChatGPT, Drive and backend modules.
